# 公開の前に探す karo の語と形

`karrybit:publish-check` に出ていく内容を調べさせるとき、依頼に「追加で探す語と形を書いたファイル」としてこのファイルのパスを書く。

## タスクと判断待ちの ID

- Beads の ID: `karo-` と、英小文字・数字の 3〜8 文字、子は `.` と数字が続く（`karo-a2v`、`karo-a2v.1`）。

## 運用の名前

- karo、Herdr、ブリーフ、Beads、`bd`。
- karo の scripts の名前: `scripts/commit`、karo-check、okf-lint、view-open と crit-open（隣の tb-view を呼ぶ）。
- `karo:land` の scripts の名前: `scripts/land`。
- `karo:herdr-agent` の scripts の名前: `agent-ctl`、agent-report。
- 記録のリポジトリのパス: `$KARO_HOME`（既定 `~/karo`）。
- 記録の名前: `standup/`、`source/meeting/`、`state.md`。
