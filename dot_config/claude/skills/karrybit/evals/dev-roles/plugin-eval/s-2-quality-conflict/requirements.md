# Requirements: 監査ログの長い期間の CSV Export

状態: 確定（プロダクトオーナーが 2026-11-02 に承認）

## 目的

- Business Goal: 年次の監査で、テナントの管理者が 1 年分の監査ログを外部の監査人に自分で渡せるようにする。
- User Goal: テナントの owner と admin が、1 年分の自分のテナントの監査ログを CSV で受け取る。

## 要求

- R-1: owner と admin は、最大 1 年の期間を指定してエクスポートを始め、終わったら CSV をダウンロードできる。
- R-2: 大きいテナントは 1 年で約 500 万行ある。エクスポートは始めてから 30 分以内に終わる。
- R-3: ストレージのキーはテナントごとの prefix（`<tenant_id>/`）の下に置き、ダウンロードの署名はその prefix の中のキーにだけ出す。セキュリティの担当が、prefix ごとに読み取りを監査している。

## 受け入れ条件

- AC-1: 500 万行のテナントで 1 年を指定すると、30 分以内に状態が「完了」になり、CSV にはそのテナントの行だけが入る。
- AC-2: テナント A の owner は、テナント B の CSV を取れない。
- AC-3: 処理が失敗すると、状態が「失敗」になり、ダウンロードはできない。

## 背景

- 運用の担当からの提案（未採否）: 「夜間に全テナントの 1 年分を 1 本の Job でまとめて共有の領域（`shared/yearly/`）に書き出しておき、要求が来たらそこからテナントの分を切り出せば、30 分に間に合う」。
