監査ログを、期間を指定して CSV で取り出せるようにしたい。このリポジトリ（管理画面の API サーバー）に入れる機能として、要求を整理してほしい。関係する記録は docs/ にある。質問があれば私には尋ねず、報告の中に書いて返して。

この仕事は karrybit:requirements-interviewer の Agent に頼み、返ってきた報告を手を加えずにそのまま最後の返事にして。その Agent を使えなければ、自分で行って同じように報告して。
