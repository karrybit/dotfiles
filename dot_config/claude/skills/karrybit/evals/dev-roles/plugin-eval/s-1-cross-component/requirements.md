# Requirements: 監査ログの CSV Export

状態: 確定（プロダクトオーナーが 2026-11-02 に承認）

## 目的

- Business Goal: テナントの管理者が、外部の監査人に監査ログを自分で渡せるようにし、サポートへの取り出しの依頼をなくす。
- User Goal: テナントの owner と admin が、期間を指定して自分のテナントの監査ログを CSV で受け取る。

## 要求

- R-1: owner と admin は、期間（最大 7 日、UTC）を指定してエクスポートを始め、状態を見て、終わったら CSV をダウンロードできる。
- R-2: 1 回のエクスポートは数分かかることがあるので、画面を閉じても処理は続く。
- R-3: CSV は 1 回のエクスポートにつき 1 ファイルで、ダウンロードのリンクは発行から 15 分で使えなくなる。

## 受け入れ条件

- AC-1: テナント A の owner が 2026-11-10 から 2026-11-11 を指定して始めると、状態が「完了」になり、ダウンロードした CSV にはその期間のテナント A の行だけが入る。
- AC-2: 期間が 7 日を超えると、始められず、理由が表示される。
- AC-3: テナント A の owner が、テナント B のエクスポートの ID を指定して状態かダウンロードを求めると、拒まれ、リンクは出ない。
- AC-4: 処理が失敗すると、状態が「失敗」になり、ダウンロードはできない。
- AC-5: member のロールの人は、エクスポートを始められない。

## 範囲の外

- 失敗のメールでの知らせ、テナントごとの同時実行数の制限、エクスポートの一覧。
