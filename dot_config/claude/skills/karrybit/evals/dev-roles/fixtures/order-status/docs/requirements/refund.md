# 要求: 注文の返金

## 目的

サポートが、支払い済みか出荷済みの注文を返金できるようにする。

## 受け入れ条件

- AC-1: 状態が `paid` か `shipped` の注文をサポートが返金すると、決済代行の返金が 1 回行われ、注文の状態は `refunded` になる。
- AC-2: 状態が `pending`、`cancelled`、`expired`、`refunded` の注文の返金は拒まれ、状態は変わらない。
- AC-3: 決済代行の返金が失敗したら、注文の状態は変わらず、サポートに失敗が伝わる。
- AC-4: 同じ注文の返金を 2 回要求しても、決済代行の返金は 1 回だけ行われる。

## 範囲の外

- 一部の返金。
