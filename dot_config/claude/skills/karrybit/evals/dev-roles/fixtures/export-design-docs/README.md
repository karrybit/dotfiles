# 監査ログの CSV Export の設計

`docs/design/` の 3 つの Design Doc は、監査ログの CSV Export を、画面・API サーバー・非同期の Job・オブジェクトストレージ・テーブルで作る設計で、どれもプロダクトオーナーが承認した。

| 文書 | 正として持つもの | 作るリポジトリ |
| --- | --- | --- |
| `console-api.md` | 画面、API サーバーの API と状態とエラー、テナントの確かめ方、署名付き URL、検証シナリオ | console（画面と API サーバー） |
| `export-job.md` | Job の名前とパラメータ、出力のキーとファイル名、暫定の CSV の列、検証用のテストデータ | jobs（Job の基盤に配る Job） |
| `storage.md` | バケット、Job の書き込みの権限、API サーバーの署名の権限、API サーバーから Job の基盤への認証 | infra（クラウドの設定） |

- 環境は dev だけ。ステージングと本番には出さない。
- dev には、この機能を確かめるためのテナントがまだない。
