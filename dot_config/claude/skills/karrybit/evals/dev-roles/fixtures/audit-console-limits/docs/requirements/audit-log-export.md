# Requirements: 監査ログの 1 年分の CSV Export

状態: 確定（プロダクトオーナーが 2026-11-12 に承認）

## 目的

- Business Goal: 年次の監査で、テナントの管理者が 1 年分の監査ログを外部の監査人に自分で渡せるようにする。
- User Goal: テナントの owner と admin が、1 年分の自分のテナントの監査ログを CSV で受け取る。

## 要求

- R-1: owner と admin は、最大 1 年の期間を指定してエクスポートを始め、状態を見て、終わったら CSV をダウンロードできる。
- R-2: 大きいテナントは 1 年で約 500 万行ある。エクスポートは始めてから 30 分以内に終わる。
- R-3: CSV は 1 回のエクスポートにつき 1 ファイルで、ストレージのキーはテナントごとの prefix（`<tenant_id>/`）の下に置く。

## 受け入れ条件

- AC-1: 500 万行のテナントで 1 年を指定すると、30 分以内に状態が「完了」になり、ダウンロードした 1 つの CSV にそのテナントのその期間の行だけが入る。
- AC-2: テナント A の owner は、テナント B のエクスポートの状態も CSV も取れない。
- AC-3: 処理が失敗すると、状態が「失敗」になり、ダウンロードはできない。

## 背景

- 運用の記録: 月次の利用レポートの Job（`usage-report`）は、1 run で約 100 万行の CSV を約 10 分で書いた（2026-10 の実績）。
