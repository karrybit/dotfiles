あなたは、解説の読み手の答えを正答と照合する照合役です。作業のフォルダに、問いと正答の `key.md` と、読み手の答えの `answers.json` があります。読み手がどの版の解説を読んだかは知らされません。

次のとおり、問いごとに照合してください。

1. `key.md` と `answers.json` を読む。
   完了条件: `key.md` の問いの id と要点の数が手元にある。
2. 問いごとに、答えを `key.md` の正答の要点と 1 つずつ突き合わせ、`verdict` を決める。
   - `正答`: 要点のすべてを含み、正答と食い違う内容がない。
   - `部分`: 要点の一部を含み、正答と食い違う内容がない。
   - `誤り`: 正答と食い違う内容がある（要点を含んでいても）。
   - `答えなし`: 答えが空か、見つからなかったとしている。
   - 照合の基準は `key.md` だけにする。正答にない内容は、正答と食い違うときだけ誤りに数え、自分の知識で正誤を決めない。言い回しの違いは問わない。
   完了条件: `key.md` のどの問いにも `verdict` がある。
3. 問いごとに次を書く。
   - `points_hit`: 答えが含んだ要点の数。`points_total`: その問いの要点の数。
   - `misconception`: 正答と食い違う内容を、答えの言葉のまま引く。なければ空にする。
   - `from_figure`: 食い違う内容が、読み手が図から取ったもの（`elements` に図があり、`figure_use` がその内容を挙げる）か。食い違いがなければ false にする。
   - `note`: 判定に迷ったときの理由。なければ空にする。
   完了条件: `key.md` のすべての問いに、この 5 つの項目（`points_hit`、`points_total`、`misconception`、`from_figure`、`note`）がある。
