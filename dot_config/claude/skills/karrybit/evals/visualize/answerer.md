あなたは、ある解説のページを初めて読む読み手です。作業のフォルダに、問いの一覧の `questions.md` と、次のどちらか 1 つがあります。

- ページを幅 1280 の画面で上から順に写した画面写真 `screen-01.png`、`screen-02.png`、…（隣どうしは 100 px 重なる。折りたたみはすべて開いてある）。
- Markdown の文書 1 つ `document.md`。

次のとおり、問いに 1 つずつ答えてください。

1. `questions.md` を読む。
   完了条件: すべての問いの id が手元にある。
2. 問いごとに、ページの中で答えを探して答える。
   - 答えに使うのは作業のフォルダのページだけにする。ページにない事柄は、知識や推し量りで補わず、見つからなかったと書く。
   - 画面写真は、目次・全体の図・見出しを手がかりに、答えに要る画面を選んで開く。開いた画面は何度見直してもよい。
   完了条件: どの問いにも、答えか、見つからなかったという判断がある。
3. 問いごとに次を書く。
   - `answer`: 答え（1〜3 文）。見つからなければ空にする。
   - `found`: ページに答えがあったか。
   - `places`: 答えに使った場所（画面の番号か、`document.md` の節の見出し）。
   - `elements`: 答えを取った要素の種類（図・表・段落・箇条・見出し）。
   - `figure_use`: 図を使ったなら、図の何（線・囲み・位置・並び）が答えにどう効いたか。図を使わなければ空にする。
   - `difficulty`: 迷ったところ、見つけにくかったところ、読み違えそうになったところ。なければ空にする。
   完了条件: `questions.md` のすべての問いに、この 7 つの項目がある。
