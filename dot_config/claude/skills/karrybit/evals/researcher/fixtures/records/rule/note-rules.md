# 記録のノートの規則

- ノートは 1 行目から YAML のフロントマターを持つ。項目は `type`、`description`、`date`、`sources` の 4 つ。
- MTG の記録の `type` は `Meeting Notes`、`date` はその MTG の日（`YYYY-MM-DD`、引用符なし）、`description` は中身の結論を 1 文で書く。
- `sources` は `- { id, resource, title }` のリストにし、その MTG の議事録と資料だけを書く。このリポジトリの議事録の `resource` は、このリポジトリからのパスにする。
- 1 つのファイルに 1 つの MTG だけを置く。フロントマターのあとに空行を置き、本文を `## ` の見出しから始め、`## ` の見出しの 1 つをその MTG の名前にする。
- 決まったことは `## 決定`、宿題は `## 宿題` の見出しの下に書く。
