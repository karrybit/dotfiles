# 商品検索を速くする計画

目的: 商品検索の 95 パーセンタイルの応答を 2 秒から 300 ミリ秒以下にする。

## G1 遅いクエリを測る

- 依存: なし
- 出力: `docs/slow-queries.md` に、遅い検索クエリの上位 10 件と所要時間を書く。
- 完了の条件: 本番の 1 週間分のログから集計した表がある。

## G2 検索専用の search_index テーブルを作り、products から写す

- 依存: G1
- 出力: このサービスの DB に `search_index` テーブルを作る migration と、`products` を読むだけで 10 分ごとに `search_index` へ写すジョブ。`products` は変えない。
- 完了の条件: `products` の全ての行が `search_index` に写り、索引があり、10 分ごとの写しが動いている。

## G3 検索 API を新しい列に切り替える

- 依存: G2
- 出力: `src/search.py` が `search_index` の索引を引く。
- 完了の条件: G1 の上位 10 件のクエリが、どれも 300 ミリ秒以下で返る。

## G4 検索の利用ガイドを書き直す

- 依存: なし
- 出力: `docs/search-guide.md` に、検索の書き方と例を書く。
- 完了の条件: ガイドの例が、今の検索 API でそのまま動く。
