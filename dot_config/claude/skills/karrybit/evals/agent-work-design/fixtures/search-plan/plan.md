# 商品検索を速くする計画

目的: 商品検索の 95 パーセンタイルの応答を 2 秒から 300 ミリ秒以下にする。

## G1 遅いクエリを測る

- 依存: なし
- 出力: `docs/slow-queries.md` に、遅い検索クエリの上位 10 件と所要時間を書く。
- 完了の条件: 本番の 1 週間分のログから集計した表がある。

## G2 products に検索用の列を足す

- 依存: G1
- 出力: `products` テーブルに `search_text` 列を足す migration と、既存の行を埋める処理。
- 完了の条件: 全ての行の `search_text` が埋まり、索引がある。

## G3 検索 API を新しい列に切り替える

- 依存: G2
- 出力: `src/search.py` が `products.search_text` の索引を引く。
- 完了の条件: G1 の上位 10 件のクエリが、どれも 300 ミリ秒以下で返る。

## G4 検索の利用ガイドを書き直す

- 依存: なし
- 出力: `docs/search-guide.md` に、検索の書き方と例を書く。
- 完了の条件: ガイドの例が、今の検索 API でそのまま動く。
