# organize の手順と評価の基準の出典

`brief.md` の型と `rubric.md` の決まりを見直すときに読む。決まりごとに、拠った出典と節を示す。表にない決まりは、この skill が自分で決めたもの。`plugin` は plannotator-effective-html（commit 5ce160a3e76d）の `skills/` の下のファイル。
